# 🌿 GrowUI - Premium Modern Developer Portfolio

GrowUI is a high-performance, minimalistic portfolio template meticulously crafted with **Next.js 16 (App Router)**, **Tailwind CSS**, and **Framer Motion**. Designed for developers who want a professional online presence that stands out.

> **Thank you for your purchase!** You now have a commercial license to use this template for your personal or client projects.

---

## ✨ Why GrowUI?

- **⚡ Next.js 16 App Router:** Leveraging the latest React features for maximum speed.
- **🎭 Smooth Animations:** Powered by Framer Motion for that "premium" feel.
- **🎨 One-File Config:** Update your name, projects, and social links in seconds via `src/config/site.ts`.
- **📱 Pixel Perfect:** Fully responsive design that looks stunning on any device.
- **🌑 Dark Mode Ready:** Beautifully crafted light and dark themes.
- **🚀 SEO Optimized:** Pre-configured metadata to help you rank on Google.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev)
- **Language:** [TypeScript](https://www.typescriptlang.org)
